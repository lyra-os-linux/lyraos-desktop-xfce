# Contrato de internacionalização do Lyra OS 1.0

O inventário canônico está em `i18n/inventory.json`. O comando
`scripts/check-i18n-inventory.py` compara suas entradas com todos os pacotes de
`obs/projects.toml`; adicionar ou remover um pacote sem atualizar o inventário
falha o gate.

Os idiomas congelados para a versão 1.0 são `en-US`, `pt-BR` e `es-ES`. `en-US` é o
padrão e o fallback obrigatório. Pacotes podem usar gettext, JSON ou catálogos
embutidos adequados à sua stack, mas cada entrada registra domínio, seleção de
locale, lint e onda de entrega. Ausência de uma tradução nunca pode produzir
uma chave crua ou impedir a execução: a resolução termina no catálogo inglês.

`complete` significa que os três catálogos e seu lint existem; `scheduled`
mantém a entrega visível e bloqueia o fechamento da onda correspondente;
`not-applicable` exige justificativa e só vale para pacote sem texto interativo
de propriedade do Lyra. Outros idiomas ficam fora da 1.0 e
só entram em um ciclo futuro com catálogo, revisão humana, fallback e gate próprios.

Execute o gate consolidado com:

```sh
python3 scripts/check-i18n-inventory.py
python3 -m unittest tests.test_i18n_inventory tests.test_installer_ui
```
